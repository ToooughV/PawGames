# Playable delivery

- Publish game builds under `Playable/<game>/`; Cubeling Defense uses `Playable/CubelingDefense/`.
- Update `Playable/CubelingDefense-release.md` when publishing a new Cubeling Defense build.
- `PokiDemo/index.html` and `PokiDemo/CubelingDefense/index.html` are legacy redirects. Preserve them; do not copy game builds back into `PokiDemo`.
- Keep game asset paths relative to the game directory. Verify the published canonical URL in README after pushing.
